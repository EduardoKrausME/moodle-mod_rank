# Moodle Plugins directory description — Ranking (mod_rank)

Ranking is a Moodle activity that lets students order **5 to 10 items** based on criteria defined by their teacher, such as importance, chronological order, priorities, or steps in a process.

Teachers create an activity, provide instructions, enter the list of items, and choose whether learners can change their response after submitting it. The configuration requires unique items without gaps. Students reorder the list by drag and drop or by using Alt + Up/Down Arrow when an item has keyboard focus, then submit their ranking.

Teachers can view a class report that groups responses and calculates the average position of each item, making it straightforward to compare the class's collective priorities or ordering decisions. Submitted responses are saved per student and can be updated only when the teacher allows it.

The plugin uses Moodle's built-in roles and permissions, and includes backup and restore, privacy support, and activity events. It requires Moodle 4.0 or later.
