# Ranking activity for Moodle (mod_rank)

Ranking is an activity in Moodle where students place between **5 and 10 items** in order, according to a criterion explained by the teacher. It works for exercises involving priority, chronology, importance, procedural steps, or comparing alternatives.

The teacher adds the activity to a course, writes instructions, enters the items and decides whether students may revise their answers after submitting. The configuration prevents duplicate items and gaps in the item list. Once there are student responses, item labels can be edited without changing the number of items.

Students reorder the items by dragging them into place or using **Alt + Up/Down Arrow** with keyboard focus, then submit their ranking. When resubmission is allowed, they can return and update their order; otherwise the previous response is displayed read-only.

Teachers can open a class report showing the number of responses and the average position assigned to each item, ordered by the group ranking. The activity includes Moodle capabilities, events, backup and restore, and user-data privacy support.

The plugin requires **Moodle 4.0 or newer** and uses Moodle's existing interface; no external ranking service is needed.

Screenshots prepared for the plugin: [student activity](https://github.com/EduardoKrausME/marketplace-plugins/blob/master/screenshots/mod_rank/new-1.png) and [additional view](https://github.com/EduardoKrausME/marketplace-plugins/blob/master/screenshots/mod_rank/new-2.png).

For Moodle's **Install plugin from ZIP file** option, download `rank.zip` from a tagged [GitHub release](https://github.com/EduardoKrausME/moodle-mod_rank/releases), rather than the generic GitHub *Source code (zip)* download. The latter uses GitHub's generated root-directory name, not the required `rank/` directory.
